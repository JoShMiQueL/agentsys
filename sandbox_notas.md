# Sandbox - Notas sobre bench.py

bench.py es una suite de benchmarks especializada diseñada para evaluar modelos de lenguaje locales ejecutados mediante la plataforma Ollama. Esta herramienta proporciona un entorno controlado para realizar pruebas exhaustivas que permiten medir el rendimiento y la calidad de los modelos, así como generar informes detallados que facilitan el análisis comparativo de las diferentes alternativas disponibles.

La suite cubre múltiples dimensiones de evaluación, desde métricas de generación de texto hasta capacidad de respuesta y coherencia, todo con el objetivo de facilitar la selección y optimización de modelos según necesidades específicas.
